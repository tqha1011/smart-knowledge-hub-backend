**Nguồn:** Đặc tả dự án DA1.pdf, chunk 20.

> 1. Lấy tập kỹ năng ứng viên = getAncestors(targetSkillIds) [gọi M2]

>

**Ý bắt buộc:**

- Lưu kết quả rỗng/NULL vào cache với TTL ngắn.
- Bloom Filter chặn ID chắc chắn không tồn tại trước khi hỏi DB.

**Nguồn:** Báo cáo mô hình hóa.pdf, chunk 19.

> · Chiến lược phòng ngự:
> o Cache Null Object: Khi DB trả về rỗng, ta vẫn lưu key -999 vào Redis
> với giá trị NULL và TTL rất ngắn (vd: 30 giây). Các request sau sẽ bị
> Redis chặn lại.
> o Sử dụng Bloom Filter: Một cấu trúc dữ liệu xác suất đặt trước Redis.

> request ngay tại cửa API mà không cần hỏi DB.
